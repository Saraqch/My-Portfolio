# Portafolio · Sara Quispe Choque

Portafolio personal hecho con React + Vite y publicado en GitHub Pages.

🌐 https://saraqch.github.io/My-Portfolio/

## Desarrollo

```bash
npm install
npm run dev
```

## Editar contenido

Todo el texto está en `src/data/es.js` (proyectos, habilidades, experiencia y contacto).
Las fotos van en `public/images/` (ver el README de esa carpeta).
Para agregar inglés más adelante, crea `src/data/en.js` con la misma estructura.

## Publicación

Cada cambio en la rama `main` se publica solo con GitHub Actions (`.github/workflows/deploy.yml`).
En el repositorio, ve a **Settings → Pages** y elige **GitHub Actions** como fuente.
